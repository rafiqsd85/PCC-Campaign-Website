
# 💙 Vote for Ayas — Campaign Website

A modern and responsive election campaign website for **Saidul Karim Ayas**, a candidate for the Vice President position of the Port City International University Computer Club.

The website presents the candidate's introduction, skills, experience, vision, promises, and contact information in a clean and professional design.

## 🌐 Live Website

🔗 **Live Demo:** [Vote for Ayas](https://vote-for-ayas.vercel.app/)

## 📌 About the Project

Vote for Ayas is a personal campaign website designed to share the candidate's profile, achievements, future plans, and commitments with students.

The goal is to provide students with a simple way to learn about the candidate and connect through social and contact links.

## ✨ Features

- 🎨 Modern and professional UI
- 📱 Responsive design for mobile, tablet, and desktop
- 🧑 Candidate introduction and profile
- 💻 Skills and experience section
- 🚀 Vision and commitments
- 🤝 Campaign promises
- 📬 Contact section with email link
- 🔗 Social media links
- ⚡ Deployed with Vercel

## 🛠️ Technologies Used

- HTML5

- JavaScript
- Vite
- Git and GitHub
- Vercel

## 🚀 Run Locally

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/rafiqsd85/PCC-Campaign-Website.git
```

### 2. Navigate to the Project Folder

```bash
cd PCC-Campaign-Website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.
